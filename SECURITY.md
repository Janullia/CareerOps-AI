# Segurança e privacidade

## Dados proibidos neste repositório

Não incluir:

- currículos reais;
- nomes, telefones, endereços ou e-mails de candidatas;
- documentos enviados por empresas ou recrutadores;
- links privados e identificadores internos;
- chaves de API, tokens, senhas ou arquivos `.env`;
- resultados reais de candidatura.

Os arquivos em `examples/` usam somente dados fictícios e o domínio reservado `example.com`.

## Aprovação humana

O workflow deve parar na etapa de aprovação. O projeto não deve enviar candidaturas, mensagens ou documentos sem decisão humana explícita.

## Relato de vulnerabilidade

Ao encontrar uma falha, não publique dados sensíveis em uma issue. Descreva apenas o comportamento técnico necessário para reproduzir o problema com dados fictícios.
